# Storefront Runtime SEO Contract Specification v1

## Purpose

This specification defines the Laravel-owned SEO payload rules for the storefront runtime.

## Supported Page Types

| Page type | Required SEO posture |
|---|---|
| `home` | canonical homepage metadata |
| `marketing_page` | localized page metadata and `WebPage` JSON-LD |
| `category_page` | localized category metadata and listing-aware canonical rules |
| `product_page` | localized product metadata and product JSON-LD |

## Required Fields

| Field | Type | Allowed values | Nullable | Example | Notes |
|---|---|---|---|---|---|
| `title` | `string` | localized string | No | `About JustShop` | Required |
| `description` | `string` | localized string | No | `Learn how JustShop delivers tenant-aware storefront experiences.` | Required |
| `canonicalUrl` | `string` | absolute URL | No | `https://demo.justshop.com/about-us` | Required |
| `robots` | `string` | `index,follow`, `noindex,nofollow`, `noindex,follow` | No | `index,follow` | Required |
| `hreflang[]` | `array` | locale/url pairs | No | see page payload example | Required for supported locales |
| `openGraph.*` | `object` | see API contract | No | see page payload example | Required |
| `twitter.*` | `object` | see API contract | No | see page payload example | Required |
| `jsonLd[]` | `array` | JSON-LD objects | No | `[{ "@type": "WebPage" }]` | Required even if only one object |

## Canonical Rules

- Canonicals are absolute tenant URLs generated by Laravel.
- Canonicals reflect the resolved locale.
- Redirected routes must not emit self-canonicalized duplicate pages.
- Not-found responses do not emit page payload SEO and instead return normalized runtime errors.

## Hreflang Rules

- The runtime must emit one hreflang entry per supported locale when an equivalent localized page exists.
- `en` and `ar` are the Phase 1 supported locales.
- Locale alternates must be tenant-safe and must not cross tenant domains.

## Structured Data Rules

- `home` and `marketing_page` emit `WebPage`-family JSON-LD.
- `category_page` emits listing-aware structured data when available.
- `product_page` emits product structured data when the page represents a product detail route.
- JSON-LD objects must be valid standalone objects and must not depend on frontend recomputation.

## Negative Rules

- Nuxt must not synthesize canonicals, hreflang, or product JSON-LD from raw backend fields.
- SEO fields must not be omitted for successful page payloads.
- Cross-tenant canonical or hreflang leakage is forbidden.
